The **Pythagorean theorem** is a fundamental relation in Euclidean geometry among the three sides of a right triangle. It states that the area of the square whose side is the hypotenuse is equal to the sum of the areas of the squares on the other two sides.

Mathematically, it is written as:


$$a^2 + b^2 = c^2$$


where $c$ represents the length of the hypotenuse, and $a$ and $b$ represent the lengths of the other two sides.

**Common Uses:**

* **Construction and Architecture:** Ensuring walls are square (using the 3-4-5 rule) and calculating roof pitches.
* **Navigation and GPS:** Triangulating locations using distances from satellites or radio stations.
* **Computer Graphics and Game Development:** Calculating distances between objects in 2D and 3D space.
* **Surveying:** Measuring land distances across obstacles.

A **hash table** (or hash map) is a data structure that stores key-value pairs. It uses a **hash function** to compute an index into an array of buckets, from which the desired value can be retrieved. This allows for an average-case time complexity of $O(1)$ for lookups, insertions, and deletions.

Here is a simple implementation in Python using chaining to handle collisions:

```python
class SimpleHashTable:
    def __init__(self, capacity=10):
        self.capacity = capacity
        self.buckets = [[] for _ in range(capacity)]

    def _hash(self, key):
        return hash(key) % self.capacity

    def put(self, key, value):
        index = self._hash(key)
        for i, pair in enumerate(self.buckets[index]):
            if pair[0] == key:
                self.buckets[index][i] = (key, value)
                return
        self.buckets[index].append((key, value))

    def get(self, key):
        index = self._hash(key)
        for pair in self.buckets[index]:
            if pair[0] == key:
                return pair[1]
        raise KeyError(key)

# Example usage:
ht = SimpleHashTable()
ht.put("apple", 5)
ht.put("banana", 8)
print(ht.get("apple"))   # Output: 5

```

=== ANSWER 3 ===
To find the second-highest salary from an `Employees` table, you can use subqueries or window functions depending on your SQL database:

**Using a Subquery:**

```sql
SELECT MAX(salary) AS SecondHighestSalary
FROM Employees
WHERE salary < (SELECT MAX(salary) FROM Employees);

```

**Using Window Functions (PostgreSQL, MySQL 8.0+, SQL Server):**

```sql
WITH RankedSalaries AS (
    SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) as rk
    FROM Employees
)
SELECT salary AS SecondHighestSalary
FROM RankedSalaries
WHERE rk = 2;

```

=== ANSWER 4 ===
The number of ways 5 people can be arranged in a row is calculated using permutations ($n!$ or $n$ factorial).

For $n = 5$:


$$5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$$

There are **120** different ways to arrange 5 people in a row.

=== ANSWER 5 ===
**Standard deviation** is a statistic that measures the amount of variation or dispersion of a set of data values. A low standard deviation indicates that values are close to the mean, while a high standard deviation indicates a wider spread.

**Computation for data: 2, 4, 4, 4, 5, 5, 7, 9**

1. **Find the mean ($\mu$):**
Sum = $40$, Count ($N$) = $8$, Mean = $40 / 8 = 5$
2. **Calculate squared deviations ($(x - \mu)^2$):**
* $(2 - 5)^2 = 9$
* $(4 - 5)^2 = 1$ (three times $\rightarrow 1, 1, 1$)
* $(5 - 5)^2 = 0$ (two times $\rightarrow 0, 0$)
* $(7 - 5)^2 = 4$
* $(9 - 5)^2 = 16$


3. **Sum the squared deviations:** $9 + 1 + 1 + 1 + 0 + 0 + 4 + 16 = 32$
4. **Calculate variance ($\sigma^2$) (population):** $32 / 8 = 4$
5. **Calculate standard deviation ($\sigma$):** $\sqrt{4} = 2$

The standard deviation is **2**.

=== ANSWER 6 ===
The ocean is salty primarily due to the continuous cycle of water eroding rocks on land and washing dissolved minerals into the sea.

Here is how the process works:

* **Rainwater Absorption:** Rainwater absorbs carbon dioxide from the atmosphere, making it slightly acidic.
* **Rock Weathering:** As rain falls and flows into rivers, this mildly acidic water breaks down minerals in rocks.
* **Mineral Transport:** Rivers carry dissolved ions (like sodium and chloride) down to the ocean.
* **Concentration Over Time:** Water evaporates from the ocean surface to form clouds—leaving the heavy minerals behind—and falls back as fresh rain, continually concentrating the salt over billions of years.
