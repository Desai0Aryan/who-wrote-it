Here is a clean, efficient implementation of quicksort in Python using list comprehensions:

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

# Example usage:
if __name__ == "__main__":
    numbers = [3, 6, 8, 10, 1, 2, 1]
    print("Original:", numbers)
    print("Sorted:", quicksort(numbers))

```

=== ANSWER 2 ===
The expected value of a fair six-sided die roll is **3.5**.

**Explanation:**
A fair six-sided die has possible outcomes of 1, 2, 3, 4, 5, and 6, each with an equal probability of $1/6$. The expected value is calculated as the sum of each outcome multiplied by its probability:

$$\mathbb{E}(X) = (1 + 2 + 3 + 4 + 5 + 6) \times \frac{1}{6} = \frac{21}{6} = 3.5$$

=== ANSWER 3 ===
The sum of the infinite geometric series $1 + \frac{1}{2} + \frac{1}{4} + \dots$ is **2**.

**Explanation:**
This is an infinite geometric series with first term $a = 1$ and common ratio $r = \frac{1}{2}$. Since $\vert{}r\vert{} < 1$, the sum $S$ converges and can be found using the formula:

$$S = \frac{a}{1 - r} = \frac{1}{1 - \frac{1}{2}} = \frac{1}{\frac{1}{2}} = 2$$

=== ANSWER 4 ===
The distance between the points $(1, 2)$ and $(4, 6)$ is **5**.

**Explanation:**
Using the distance formula $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$:

$$d = \sqrt{(4 - 1)^2 + (6 - 2)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$
