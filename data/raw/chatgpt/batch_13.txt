```
public static boolean areAnagrams(String s1, String s2) {
    if (s1 == null || s2 == null || s1.length() != s2.length()) {
        return false;
    }

    int[] counts = new int[256];

    for (int i = 0; i < s1.length(); i++) {
        counts[s1.charAt(i)]++;
        counts[s2.charAt(i)]--;
    }

    for (int count : counts) {
        if (count != 0) {
            return false;
        }
    }

    return true;
}
```

 This treats uppercase/lowercase and spaces as different characters. For example, `"listen"` and `"silent"` return `true`.

 === ANSWER 4 ===

 **Inflation** is a sustained increase in the overall price level of goods and services in an economy. As prices rise, each unit of currency generally buys fewer goods and services, meaning its purchasing power falls.

 Common causes include:

 - **Demand-pull inflation:** Demand for goods and services grows faster than the economy's ability to produce them.
- **Cost-push inflation:** Production costs, such as wages, energy, or raw materials, increase and businesses raise prices.
- **Supply disruptions:** Events such as natural disasters, wars, or transportation problems can reduce supply and push prices higher.
- **Monetary factors:** Rapid growth in the money supply can contribute to inflation when it exceeds the economy's capacity to produce goods and services.

 Inflation can have different effects depending on its rate, duration, and underlying cause. Moderate, stable inflation is generally viewed differently from sudden or persistently high inflation.

```
def is_balanced(s):
    balance = 0

    for char in s:
        if char == '(':
            balance += 1
        elif char == ')':
            balance -= 1

            # A closing parenthesis appeared without
            # a matching opening parenthesis.
            if balance < 0:
                return False

    return balance == 0
```

 Examples:

```
is_balanced("(hello)")   # True
is_balanced("(()())")    # True
is_balanced("(()")       # False
is_balanced("())(")      # False
```

 === ANSWER 6 ===

```
def remove_duplicates(items):
    return list(dict.fromkeys(items))
```

 Example:

```
remove_duplicates([3, 1, 3, 2, 1, 4])
# [3, 1, 2, 4]
```

 `dict` preserves insertion order in modern Python, so the first occurrence of each item is retained.
