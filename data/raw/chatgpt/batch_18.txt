 The main causes of World War I were a combination of long-term tensions and immediate events:

 - **Militarism:** European powers expanded their armies and navies and developed detailed military plans, increasing the risk that a crisis would escalate into war.
- **Alliances:** Europe was divided into competing alliance systems, particularly the **Triple Alliance** (Germany, Austria-Hungary, and Italy) and the **Triple Entente** (France, Russia, and Britain). These alliances meant a conflict between two countries could draw in others.
- **Imperialism:** Competition for colonies and economic influence, especially in Africa and Asia, intensified rivalries among European powers.
- **Nationalism:** Strong national identities and nationalist movements created tensions, particularly in the Balkans, where Slavic nationalist movements challenged the Austro-Hungarian Empire.
- **Balkan instability:** The decline of the Ottoman Empire created competition among Austria-Hungary, Russia, Serbia, and other powers over territory and influence.
- **The assassination of Archduke Franz Ferdinand:** On June 28, 1914, Serbian nationalist **Gavrilo Princip** assassinated Austria-Hungary's heir in Sarajevo. Austria-Hungary declared war on Serbia, triggering a chain of mobilizations and declarations of war.

 The assassination was the **immediate trigger**, but the underlying causes had built up over decades.

 === ANSWER 3 ===

```
def dfs(graph, start):
    """Perform depth-first search on an adjacency-list graph.

    Args:
        graph: Dictionary mapping each node to an iterable of neighbors.
        start: Node from which to begin the search.

    Returns:
        A list of nodes in the order they were visited.
    """
    visited = set()
    result = []

    def visit(node):
        if node in visited:
            return

        visited.add(node)
        result.append(node)

        for neighbor in graph.get(node, []):
            visit(neighbor)

    visit(start)
    return result
```

 For example:

```
graph = {
    "A": ["B", "C"],
    "B": ["D", "E"],
    "C": ["F"],
    "D": [],
    "E": [],
    "F": []
}

print(dfs(graph, "A"))
```

 This visits nodes by going as deeply as possible along each branch before backtracking.

 === ANSWER 4 ===

 A neural network learns by **adjusting its internal parameters so that its predictions become more accurate**.

 The basic process is:

 1. **Input:** Data is fed into the network, such as an image, sentence, or set of numerical measurements.
2. **Forward pass:** The data moves through layers of neurons. Each neuron applies weights, adds a bias, and passes the result through an activation function.
3. **Prediction:** The final layer produces the network's output.
4. **Loss calculation:** The prediction is compared with the correct answer using a **loss function**. The loss measures how wrong the prediction was.
5. **Backpropagation:** The network calculates how much each parameter contributed to the error using derivatives.
6. **Parameter update:** An optimization algorithm, commonly **gradient descent**, adjusts the weights and biases to reduce the loss.
7. **Repeat:** This process happens repeatedly across many examples.

 Over many training iterations, the network learns parameter values that allow it to recognize patterns and make useful predictions on new data.
